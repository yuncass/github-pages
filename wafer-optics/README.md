# 웨이퍼 반사 · 흡수판 계산기

[계산기 열기](https://yuncass.github.io/github-pages/wafer-optics/) · [기존 인쇄 도구](https://yuncass.github.io/github-pages/)

300 mm 웨이퍼를 바라보는 산업용 카메라에서 역방향으로 정반사 광선을 추적하고, 흡수판 평면에서 웨이퍼 전체에 대응하는 영역을 계산하는 정적 웹앱입니다. 별도 빌드, 서버 계산, 외부 스크립트/CDN, 계정 또는 API 키가 필요하지 않습니다. 최신 브라우저의 JavaScript와 Canvas 2D를 사용합니다.

## 기본값과 사용

| 항목 | 기본값 |
|---|---|
| 카메라 | HIKROBOT MV-CS050-10GM |
| 전체 센서 해상도 / 픽셀 크기 | 2448 × 2048 / 3.45 μm |
| 계산한 센서 유효 크기 | 8.4456 × 7.0656 mm |
| 렌즈 초점거리 | 8 mm |
| 웨이퍼 지름 | 300 mm |
| 카메라 광학 중심과 웨이퍼 중심 사이 거리 | 650 mm |
| 웨이퍼 법선 기준 관측각 | 45° |
| 반사 중심축 위 기준점까지 거리 | 400 mm |
| 흡수판 기준 자세 | 중심 반사광에 수직 |
| 판 중심 | 반사 영역의 가운데로 자동 이동 |
| 각 변의 여유 | 5 mm |

이 기본 배치의 최소 사각형은 약 352.048908 × 491.199141 mm입니다. 각 변에 5 mm 여유를 더한 필요 크기를 0.1 mm 단위로 올림하여 **362.1 × 501.2 mm**로 표시합니다. 이 값은 예시 배치의 결과이며 실제 설치 거리와 각도를 입력해야 합니다.

1. 광학 중심에서 웨이퍼 중심까지 거리와 법선 기준 관측각을 입력합니다. 본체 앞면에서 잰 작업거리와 광학 중심 거리는 다를 수 있습니다.
2. 판 거리의 기준을 선택합니다. `중심 반사축을 따라 잰 거리`는 O에서 A까지, `수직 높이`는 A의 z 좌표입니다. 자동 중심 배치로 최종 판 중심이 A에서 이동하므로, 설치 시 결과의 판 중심 X·Y·Z도 확인합니다.
3. 판의 기준 자세, 국소축 U·V 기울기, 면내 회전을 조절합니다. 회전 순서는 U축 기울기 → 회전된 V축 기울기 → 새 법선 주위의 면내 회전입니다.
4. 자동 중심 또는 고정 중심을 선택합니다. 고정 중심의 U·V는 기준점 A에서 판 위로 이동한 좌표입니다. 판 평면은 유지되며 필요한 사각형의 크기가 달라집니다.
5. 실제 판 크기를 입력하거나 `계산된 필요 크기를 실제 판에 적용`을 누릅니다. 판 포함 여부, 여유, 카메라 시야 및 시선 가림을 확인합니다.
6. 3D 배치는 드래그/방향키로 회전, 휠/+/−로 확대할 수 있습니다. 2D 탭에서 판 좌표와 센서 투영을 확인합니다. 모바일에서는 `카메라·흡수판 입력 설정`을 펼칩니다.

길이 표시 단위는 mm/cm/inch입니다. 렌즈 초점거리와 센서 크기는 항상 mm입니다. 단위를 바꿔도 내부 물리량은 유지됩니다. 모든 계산과 JSON·CSV의 공간 좌표는 mm, 각도는 도(degree)입니다. JSON은 내부 수치와 화면 단위를 별도로 기록합니다.

네 가지 기본 배치와 브라우저에 저장하는 사용자 배치를 제공합니다. 브라우저 자동 저장은 동일 출처에만 적용됩니다. 공유 링크는 설정을 URL의 해시 안에 담습니다. JSON은 설정과 결과를, CSV는 0.5° 간격의 720개 경계 광선 교차 좌표를 보관합니다. CSV 표본에서 치수 경계를 다시 구하면 해석적 최소값과 미세하게 다를 수 있습니다.

## 계산 모델

웨이퍼: `P=(x,y,0)`, `x²+y² ≤ R²`, 법선 `N=(0,0,1)`.

카메라: `C=D(sinθ cosφ, sinθ sinφ, cosθ)`. 항상 웨이퍼 중심을 바라봅니다. 반사 중심축은 `B=(-sinθ cosφ,-sinθ sinφ,cosθ)`입니다.

카메라에서 P로 보내는 역광선 `d=P-C`를 반사하면 `r=d-2(d·N)N=(x-Cx,y-Cy,Cz)`입니다. 판 기준점 A와 법선 n에 대해:

```
t = n·(A−P) / n·r
Q = P + t r
U = u·(Q−A), V = v·(Q−A)
```

웨이퍼의 모든 점에서 분모가 0이 아니고 `t>0`이어야 합니다. 분모가 원판 내에서 부호를 바꾸거나 0에 닿으면 유한한 경계가 없는 배치로 처리합니다. t의 최솟값이 0 이하인 배치도 크기를 표시하지 않습니다.

U·V 좌표와 센서 투영은 원판 위의 선형분수 함수 `g(P)=(a0+a·P)/(b0+b·P)`입니다. 분모의 부호가 일정할 때, 극값은 원판에 접하는 직선의 조건에서 직접 계산합니다:

```
(a0 − q b0)² = R² |a − q b|²
```

부동소수점 상쇄를 줄이기 위해 중심값 `a0/b0`를 뺀 식을 풉니다. `Umax−Umin`, `Vmax−Vmin`이 **현재 판 축 방향에서 중심을 옮길 수 있을 때**의 최소 사각형입니다. 면내 회전을 포함한 전역 최소 면적 최적화는 하지 않습니다. 고정 중심은 각 축에서 가장 먼 극값까지 거리의 두 배를 사용하고, 여유는 각 치수에 두 배를 더합니다.

센서 검사는 카메라 좌표의 `f X/Z`, `f Y/Z`를 같은 방식으로 경계 계산합니다. 카메라 위치가 같으면 초점거리와 센서 크기는 시야만 바꾸며, 웨이퍼 전체의 반사 영역을 바꾸지 않습니다. 시야 밖의 웨이퍼 영역도 판 크기 계산에 포함됩니다.

전체 포함 여부와 전체 센서 시야 판정은 표본 개수와 무관한 해석적 검사입니다. 면적 백분율과 실제 판의 카메라 시선 가림은 황금각으로 배치한 균등 면적 원판 표본 2,048개로 추정합니다. 100% 표본 포함이 해석적 전체 포함을 뜻하지는 않습니다. 아주 작은 가림은 표본에서 놓칠 수 있습니다. 시선 가림은 `P→C` 선분이 입력한 실제 판의 사각형과 교차하는지 검사합니다.

평평한 웨이퍼, 이상적인 정반사, 단일 광학 중심, 왜곡 없는 핀홀 카메라, 두께 없는 판을 가정합니다. 유한 입사동공, 렌즈 왜곡·초점·심도, 웨이퍼 휨/거칠기, 다른 기구물, 판의 앞뒷면 흡수율은 모델에 포함하지 않습니다. ROI나 크롭을 사용하는 경우 센서 유효 크기를 수정하세요. 실제 적용에는 광학 보정 및 설치 오차에 맞는 여유가 필요합니다.

## 검증과 로컬 실행

Node.js 22 이상에서 저장소 루트 기준:

```sh
node --test wafer-optics/tests/geometry.test.mjs
```

17개 검증: 정면 평행판 닫힌식, 경사 관측 수평판, 독립 광선 반사 법칙, 12,000개 경계 광선 비교, 센서 접경, 평행 특이점, 역방향 교차, 회전/스케일 일관성, 고정 중심, 시선 가림, 유효성 검사, 무작위 배치의 원판 내부 경계, 작은 미포함 영역, 수평판 직접 교차식, 법선 반전, 카메라 센서 사양.

브라우저의 `계산 검증 실행`은 이 중 Node 의존성이 없는 12개 검증을 같은 코드로 실행합니다. 설정값을 변경하지 않습니다. 실행 실패는 검증 결과에 표시합니다.

로컬에서는 저장소 루트를 일반 정적 HTTP 서버로 제공하고 `/wafer-optics/`를 엽니다. 예를 들어 Python이 설치되어 있다면 `python -m http.server 8000 --bind 127.0.0.1` 실행 후 `http://127.0.0.1:8000/wafer-optics/`로 접속합니다. ES 모듈 때문에 HTML 파일을 `file://`로 직접 여는 실행은 지원하지 않습니다.
